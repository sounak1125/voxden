The installer lets you pick the folder and makes a desktop shortcut. Nothing is asked of you until the app opens.

First run

Windows will warn you. Here is why, and what to click.

  1. 01

    Run the installer

    Open the file your browser just saved. If the browser holds it back, choose Keep from its download menu first.

    Voxden-Setup-2.1.2.exe
  2. 02

    Click "More info"

    A blue screen says Windows protected your PC. The link sits under the message, above the button.

    Windows protected your PC

    Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk.

    More info

    Don't run
  3. 03

    Click "Run anyway"

    The screen grows two lines and a second button. Publisher reads Unknown, because the build is unsigned.

    Windows protected your PC

    App: Voxden-Setup-2.1.2.exe

    Publisher: Unknown publisher

    Run anywayDon't run

Why this happens. Voxden isn't code-signed yet. SmartScreen is reporting that it has not seen this installer before, not that it found anything in it: with no certificate there is no publisher name to recognise, so every new version starts from zero reputation. A certificate costs more than the app earns today, so signing comes at around 100 to 200 paying users. Until then the file here is the same one attached to the GitHub release, and these prompts appear once per version.

After install

What happens the first time you open it.

  1. 1

    Sign in

    Voxden asks for an account before anything else: Google, or a code sent to your email if you would rather not use Google. The email address is the account; Google also brings your name and picture.

  2. 2

    Pick where your voice goes

    Download a speech model to run on your own machine — Qwen3-ASR or Whisper, on the GPU if you have one and the CPU if you don't — or switch Voxden Cloud on if you are on Pro and skip the download entirely.

  3. 3

    Press the keys and talk

    The flow bar appears wherever your cursor is. Press once to start and once more to stop, or hold both keys while you speak. The text lands in whatever you were typing in.

    Ctrl+ to dictate

Checksums and source: every release on the GitHub release page carries the installer, its blockmap and latest.yml, the update manifest holding the installer's SHA-512 — the same file Voxden reads when it updates itself. The code is in the repository.
