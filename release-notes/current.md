Version: 2.1.8
Released: 5 October 2026

Fixes for the Windows taskbar, games and fullscreen apps. The game shortcut now starts off: turn it on in Settings, under Shortcuts.

## What's new

- Taskbar popups, such as the list of an app's open windows, stay open again while Voxden is running. In 2.1.7 they could close as soon as they opened.
- While the game shortcut is off, its key works normally in your other apps. If you used it in 2.1.7, turn it on again.
- Dictating into a game keeps you in the game: Voxden no longer opens its window over it, and Escape and mouse clicks go to the game.
- The flow bar steps aside for a fullscreen app only when the app is on the bar's screen, and it waits a moment before coming back, so it no longer slides in and out. The Start menu and other Windows popups leave it where it is.
- If a fullscreen game or film is in front when your words are ready, Voxden no longer pulls another window over it. Your words wait on the clipboard, and the flow bar asks you to press Ctrl+V.
- A single-key shortcut, such as F8, no longer fires when you press it with Shift, Ctrl, Alt or Windows, so Shift+F8 in an editor stays the editor's. In a fullscreen game it still works while you hold a key like sprint.
- Voxden no longer notes every app that runs as administrator, such as Task Manager or the Windows sign-in prompt. It tells you when it cannot paste into one, or when a fullscreen game runs as administrator, and the older notes are cleared.

## Installing or updating

**Windows:** Install the update in Voxden or download the installer. Voxden is not yet code-signed; if SmartScreen appears, choose **More info**, then **Run anyway**.

**Mac:** Download the Apple Silicon build from [voxden.app/download](https://voxden.app/download) and replace Voxden in Applications. Mac updates are installed manually. Follow the first-run steps on the download page if macOS blocks opening the app.
